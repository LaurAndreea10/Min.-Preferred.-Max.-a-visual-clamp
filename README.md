# Min. Preferred. Max. — A Visual Clamp

A front-end visual experiment built as part of a personal portfolio, designed to illustrate the relationship between limits, preferences, and responsive behavior in a clear and interactive way.

## Live Demo

https://laurandreea10.github.io/Min.-Preferred.-Max.-a-visual-clamp/

## Features

* Visual explanation of clamp-related behavior
* Interactive front-end presentation
* Clear and structured UI layout
* Responsive design concept
* Educational and exploratory interface
* GitHub Pages deployment

## Technologies

* HTML
* CSS
* JavaScript
* GitHub Pages

## Purpose

This project was created as a personal front-end experiment to make abstract layout and sizing logic easier to understand through a visual and interactive browser-based experience.
